# Website Features and Functionalities

## Candidate Site

The website consists of a Login/Sign-up page for colleges as well as students, with a User ID and Password.

The Candidate site will consist of the candidate's details, preference submission, allocation details, and payment window.

### Candidate's Details

On this page, students can fill in their personal and academic details for the purpose of college allocation.

**Details to be filled in by the student:**

* Name
* Roll No.
* Contact Information
* Date of Birth (DOB)
* Academic Information
* Address
* Category
* Nationality

### Preference Submission

This page will contain a list of different courses offered by colleges. Students can add courses from their respective colleges to their preference list and submit it.

### Allocation Details

This page will show the student's allocation results after each round.

**Information available on this page:**

* Round Number
* Payment Status
* Allocated Course Name

### Payment Details

This section contains an external link that provides various payment options.

**Main features of this page:**

* **Payment Overview**
* **External Link for Fee Payment** (such as UPI, debit/credit cards, wallets, etc.)
* **Payment Status**

---

## College Site

The College site consists of pages for viewing/editing college details, viewing student details, and college registration.

### College Registration Page

This page allows new colleges to register for the allocation process and provide all the necessary details for participation.

**Necessary details to be filled in by the college:**

* College Name
* Location
* Contact Information
* Programs Available
* Total Seats for a Course
* Type of Institute

### View/Edit College Details

This page contains information about the seats available at the college for different courses and programs. Colleges can also update their details.

**Colleges can view the following information:**

* College Name
* Location
* Type of Institute
* Contact Information
* Course-wise Seat Information

**Colleges can change details such as:**

* Add or Remove a Branch or Program
* Change the Number of Seats for Course(s)
* Contact Information

### Student Details

This page allows colleges to view the details of students admitted to their institute. They can also filter students according to their programs and courses.

**Student details to be shown:**

* Student's Name
* Student's Roll No.
* Student's Rank
* Course Name
* Program Name
* Quota
* Contact Information

**Search and Filters Available:**

* Filter by Program
* Filter by Course
* Filter by Quota
